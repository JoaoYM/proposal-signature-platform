# Fluxo de entrega assistida

1. Copie `templates/card.md` para `cards/<id>.md` e registre objetivo, critérios e riscos.
2. Escreva ou atualize o Gherkin em `acceptance/src/test/resources/features`.
3. Implemente o menor incremento que faça o cenário passar.
4. Execute os `verify` de CRM, SIGN e `acceptance`.
5. Atualize a coleção Insomnia e registre as evidências no card.

Nenhum card está concluído sem comandos reproduzíveis, resultado esperado e riscos residuais explícitos.
